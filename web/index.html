morg

A bidirectional Markdown ↔ Org-mode converter built for keeping one format as the canonical store of a second brain while editing in the other.

It is semantically faithful and convergent: content is preserved, and after one round trip further conversions are byte-for-byte stable in both directions. Markdown-only constructs survive the trip through Org as morg_ properties; Org-only constructs travel through Markdown as key:: value conventions. Frontmatter travels inert in a marked Org comment block, not as Org keywords, which can act in Emacs. Dialect presets for Logseq and Obsidian are built in, one per side of a conversion: Logseq Org to plain Markdown is as much a conversion as Logseq Org to Logseq Markdown. The Logseq preset converts a page as Logseq's outline of blocks, a headline in Org, a bullet in Logseq Markdown and a list item in plain Markdown per block, and maps page properties to the #+key: lines Logseq reads. Two dialects of one format translate, Logseq Markdown to plain Markdown say, changing only what the two write differently.

Try the converter

The converter runs entirely in your browser. Nothing is uploaded, no tracking.

For whole files and for automation, morg is also a CLI and a TypeScript library, published on npm as @remigius42/morg. It needs no install to try: 

npx @remigius42/morg \
  --input notes.md --output notes.org

See the repository for the mapping reference, configuration and the library API.
