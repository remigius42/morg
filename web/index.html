morg

A bidirectional Markdown ↔ Org-mode converter built for keeping one format as the canonical store of a second brain while editing in the other.

  • Convert Markdown ↔ Org, in Vanilla, Logseq or Obsidian dialect per side.
  • Translate between two dialects of one format, changing only what they write differently.
  • Faithful and convergent: content is preserved, and after one round trip further conversions are byte-for-byte stable.
  • What only one format has travels in the other's own syntax or marked, and comes back; what cannot is reported as a warning.

Try the converter

The converter runs entirely in your browser. Nothing is uploaded, no tracking.

For whole files and for automation, morg is also a CLI and a TypeScript library, published on npm as @remigius42/morg. It needs no install to try: 

npx @remigius42/morg \
  --input notes.md --output notes.org

See the documentation for the mapping reference, configuration and the library API.
